# Third-party source and assets

The `grids/` reference firmware source, the embedded factory drum-map tables,
and the bundled `grids_1.0.wav` are from Mutable Instruments Grids by Emilie Gillet.
Retain the original copyright and license notices in the upstream files.
The reference firmware files identify their license as GPL version 3 or later;
the generated resource files retain their own license notices.

The source upload package includes the reference firmware code used by the
regression checks. It excludes optional upstream hardware CAD files and local
vendor checkouts. Building the web app does not require those checkouts.
